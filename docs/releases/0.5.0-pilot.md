PolicyCompass now runs locally through your web browser. Download the Windows
installer, install it for your user account and open the PolicyCompass shortcut.
Python and the application libraries are included.

- Compare policy documents against one or more supported frameworks.
- Download frameworks from their publishers or import an AESCSF Core workbook.
- Review matching passages, unmatched requirements, documents and saved history.
- Export HTML, CSV, Markdown and JSON reports, or download a `.policycompass` file.
- Keep preferred settings and reuse an already running application instance.

Choose the file ending in **windows-x64-setup.exe** for normal installation.
The **portable.zip** contains the same application; extract the whole folder
before opening `PolicyCompass.exe`.

This is an **unsigned pilot for 64-bit Windows**. Example policies, publisher
documents and saved comparisons are excluded from both downloads. Use Framework
updates on first launch. The normal AESCSF workbook import remains available.

The release includes SHA-256 checksums, a dependency list and a manifest recording
the source revision and packaged files. Application tests and a fresh-workspace
check of the compiled core run before publication.
